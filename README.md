# 学习闭环 · 30 天计划生成器

把一本专业书拆成 Day 0 到 Day 30 的逐日动作表，配合六步学习法、番茄钟、知识点卡片，形成一个"学新 → 检索 → 间隔重复 → 建网"的闭环。

单文件网页，双击就能用：不需要装环境、不需要联网、不依赖任何框架或 CDN。

**在线体验：** https://chengyi-mountain.github.io/study-loop/ —— 手机、电脑都能直接打开，不用下载；离线使用就把 `index.html` 存到本地双击。

---

## 快速开始

1. 双击 `index.html`，用浏览器打开
2. 输入书名（或直接点下方的内置书目）→ 点 **🔍 查章节**
3. 在弹框里勾选要学的章节（默认全不选，只有建议先学的章节有黄色高亮；也可以点"只选建议章节"一键选）
4. 点 **生成我的学习计划** → 自动排出 31 天
5. **书不在内置库里？** 两种都行：① 配一个抓取服务（`outline-fetcher/`，本地或云端），输入书名点查章节就**自动联网出目录**；② 不配服务也行——点「📥 任意书」→「📋 读剪贴板」，把刚从微信读书/豆瓣复制的目录贴进来，或者只填章数生成占位标题。导入一次之后，这本书就跟内置书目一样查、勾、排

选中章节后若什么都不勾直接生成，会按该书内置的建议章节兜底，不会给你一张空表。

**下次打开会记住上次**：浏览器一打开就直接回到上次那张计划表（同一本书、同一个投入、同一批章节），不用重新查一遍；想换书点计划页上的「换一本书」。

## 计划是怎么排出来的

- **31 天**：Day 0 ~ Day 30，每天一张卡，卡片上有当天任务、每项任务的分钟数、以及"产出"要求
- **6 个固定检索节点**：Day 0 / 1 / 3 / 7 / 14 / 30，对应"当天闭卷默框架 → 整章重默 → 三天后合卷 → 一周回顾 → 半月整合 → 月末全书闭卷"。节点日不会被学新内容挤掉，新内容会绕开它
- **日型分三类**：检索节点日（橙色竖标）、学新内容日、机动日（按回炉 / 混合 / 拓展轮着来）。勾选的章节按"总章节数 ÷ 学习日数"均分到学新日，剩下的日子不塞新内容，只做回顾、补漏和拓展
- **每天 3~7 项任务**：预算紧时精简到 3 项核心，预算宽裕时自动补 1~2 条加练（回炉已学章节），第一项是 3 分钟的短任务，用来"把脑子拽回来"
- **每天投入（30 / 45 / 60 / 90 / 120 分钟）是真预算**：扣掉 5 分钟机动后，剩余全部落到当天任务上
  - 30 分钟 → 全天约 25 分钟，砍到「带问题进场 / 只记关键词 / 闭卷默框架」三项，不硬塞五项
  - 45~60 分钟 → 标准六步流程，全天 35~55 分钟
  - 90~120 分钟 → 单节环节放到上限（记关键词最多 35 分钟），剩下的时间补加练，全天 73~115 分钟
  - 预算连三项都装不下时，计划页顶部直接给建议分钟数；章节多到 31 天排不完时会提示少勾几章
  - 计划页右上角也有同一个下拉，改完立刻重排，不用退回起始页

计划页顶部有统计卡（共排几节 / 每天几分钟 / 几个检索节点 / 几个学习日）、打卡进度条、筛选器（全部 31 天 / 只看检索节点日 / 只看未打卡），复选框打卡会即时存盘。

## 四个页签

| 页签 | 作用 |
| --- | --- |
| 学习计划 | 31 天逐日动作表、打卡、筛选、换书重排、清空打卡 |
| 六步学习法 | 完整方法论：五条底层逻辑表、六步闭环详解（每步的动作 / 工具 / 关键）、检索节奏表（第 0~5 次各练什么）、卡壳与拖延的补充模块 |
| 番茄钟 | 专注时长 15 / 25 / 45 / 60 快选 + 自定义（1–180 分钟，记住上次）；内置合成白噪音；倒计时结束铃声 + 标题闪烁 + 系统通知；可填"这个番茄做什么"，四个番茄进长休息 |
| 知识点总结 | 顶部列出**所选章节**，一行一章、点哪章就带着章节去写卡；卡片按章分组；三句话（定义 / 区别 / 例子）+ 三方向（深度 / 横向 / 纵向），支持搜索、自测、**背诵稿**（遮答案背诵、复制全文/本章、导出 txt）、导出待填模板 |

### 番茄钟：调时长、放白噪音、结束一定要吵醒你

- **专注时长自己定**：15 / 25 / 45 / 60 四个快选，或直接填分钟数（1–180）。改完立刻生效，下次打开还是这个值；休息固定 5 / 20 分钟。
- **白噪音**：棕噪声（沉稳的沙沙）/ 雨声 / 海浪（一阵一阵），浏览器现场合成，**不需要音频文件、断网也能放**；音量滑杆随时调。点开始自动响，暂停或结束自动停——不会忘了关。
- **结束提醒**三件事一起做，切到别的页面也漏不掉：
  1. 6 声渐高的铃声（浏览器允许的范围内，不需要任何音频素材）
  2. 页面横幅弹出"⏰ 时间到，先站起来"
  3. 标签页标题变成 `⏰ 专注结束，去休息` 并闪烁，回到页面自动恢复
  4. 可选**系统通知**（首次点开始会问你要权限；不想收就在设置里取消勾选）

### 知识点总结：按你选的章节来写

- 顶部一块「**所选章节知识点总结**」：把计划里排进的所有章节一行一章列出来，右边显示"待补 / 已写 N 张卡"。
- 点某一章的「写这张卡」→ 页面自动跳到写卡区，并挂上"正在给「第 X 章 …」写卡"的标签；保存时卡片会记住章节，**继续给同一章写也不用手动切**（点"不关联章节"可解除）。
- 卡片列表自动**按章分组**（📖 章节名 · N 张），没关联章节的老卡片统一收到"未关联章节"；搜索或自测时改成平铺，方便一屏扫完。
- 「导出待填模板」：把每章按"一句定义 / 一句区别 / 一句例子 / 三方向"排成空白 txt，打印出来手写或者带到别处填都行。
- 「**背诵稿**」：把已写的卡片按章节排成一份复习稿。默认先遮住答案自己背，点单张「看答案」掀开，或一键「显示答案」；支持**复制全文**、**复制本章**、**导出 txt** 带走。新写 / 删除卡片后背诵稿自动刷新。（背诵稿汇总的是你自己写过的卡片，网页不联网、也没有书本正文，不会自动概括章节内容。）

## 任意书都能用（目录导入）

内置 6 本只是"开箱即用"的样例，任何书都能用。两条路，优先走第一条：

| 路径 | 你要做的事 | 手机 |
| --- | --- | --- |
| **① 抓取服务（推荐）** | 什么都不用做：输书名 → 点查章节 → 直接出目录 | 云端版可用 |
| ② 复制粘贴 | 搜索页复制目录 → 切回来 → 自动接上 | ✅ |

### ① 抓取服务：输入书名直接出目录

网页是纯静态的，抓第三方页面会被 CORS 拦掉；所以另起一个零依赖小服务替它抓，
数据源是微信读书**公开**阅读页里内嵌的 `chapterInfos`（不用登录、不要会员）。
服务在 [`outline-fetcher/`](outline-fetcher/) 里，两个版本：

- **本地版** `outline-fetcher/local.js`：`node outline-fetcher\local.js` 起一个 `http://127.0.0.1:8765`，页面会自动发现它。电脑用，不用部署。
- **云端版** `outline-fetcher/worker.js`：粘到 Cloudflare Workers 一键部署，拿到 `https://xxx.workers.dev`，填进「导入弹框 → 抓取服务」，**手机也能全自动**。

配好之后：输入书名 → 点 **🔍 查章节** → 抓不到内置的就自动联网 → 直接弹出章节勾选框。
抓不到（付费/无公开目录的书）会自动退回下面第②条，不会卡住，也不乱猜——书名跟关键词对不上时它宁可说"没搜到"。

实测命中：太乙金华宗旨 13 章、认知天性 59 章、人类简史 65 章、如何高效学习 15 章、
道德经 83 章、红楼梦 120 回、三体全集 102 节、国富论 45 章。

### ② 复制粘贴（没配服务时的兜底）

一次完整的扫码动作：

1. 输入一本没有内置目录的书 → 点 **🔍 查章节**，会提示没这本，并给出「微信读书搜这本书 / 豆瓣搜这本书」
2. 点其中一个 → 导入弹框已经先替你备好（书名填好、光标在输入框），新窗口里找到这本书的目录页
3. **全选复制那段目录，切回本页 —— 就完事了**：程序自动读到剪贴板，认到 ≥3 章就直接导入并弹出章节列表（不用再点任何按钮；浏览器没给剪贴板权限时才需要点「📋 读剪贴板」或按 Ctrl+V）
4. 勾章节 → 生成 31 天计划

> 切回来这件事有三重触发：`focus` 事件、`visibilitychange`、以及每 1.5 秒一次的轮询（页面在前台才读）。任意一个生效就够，所以偶发"切回来没反应"会被兜住；读不到就安静地等下一次，不会乱导入。

解析规则（对付各种复制粘贴的脏版面）：

| 认得出 | 说明 |
| --- | --- |
| 第X章 / 第X讲 / 第X课 / 第X回 / 第X节 / 第X部 / 第X篇 / 第X卷 / 单元 / 模块 / 专题 | 章节标题行 |
| Chapter N / Part N / Lecture N / Unit N / Section N / §N | 英文与符号写法 |
| 序言 / 自序 / 前言 / 引言 / 绪论 / 导论 / 总论 / 上篇 / 下篇 / 结语 / 尾声 / 后记 / 跋 / 附录 / 参考文献 / 致谢 / 索引 | 前后附加部分 |
| 1 绪论、1. 绪论、一、绪论 | 二维码编号式目录（≥3 条才按这个结构认） |
| "第一章"单独一行、下一行才是章名 | 自动合并成一章 |

同时自动丢掉：书名/作者/译者/出版社/ISBN/定价/开本/印张/字数/版次/印次/装帧/版权/CIP/上架建议/「加入书架」「开始阅读」这类按钮文字、纯页码行、点线（`…… 15`）、网址、分隔线。编号前缀（`第一章`、`1.`、`一、`）统一剥掉，只留章名，编号由 `n` 管。

- 导入结果存本地，下次打开还在，也会出现在「学习档案」和书目 chips 里（带 📥 角标）
- 内置 6 本永远优先，不允许被同名导入覆盖；导入的书没有简介，章节行显示"（这篇目录没带简介）"

> 为什么"网页自己"抓不了：实测五条路全不通——① 境外书目接口（Google Books / OpenLibrary）本机 20 秒超时；② 豆瓣 / 微信读书 / 当当都返回 200，但**响应里没有 CORS 头**，页面里的 `fetch` 会被浏览器直接拦掉；③ 豆瓣的 `callback=` 参数被忽略，做不了 JSONP；④ CORS 代理 r.jina.ai 连不上、allorigins 返回 520、corsproxy.io 要授权、codetabs 超时、cors.lol 429、thingproxy 域名已不存在；⑤ 微信读书取目录的接口不带登录态一律 401/404。所以"由程序去抓"必须先有一台服务（就是 `outline-fetcher/`），而它一旦存在，跨域问题就消失了——服务端没有 CORS 限制。

## 数据存在哪

章节选择、打卡记录、知识点卡片、番茄计数、学习档案、自己导入的目录都只存在**你自己浏览器**的 localStorage 里（键位：`xh_progress_v1` 打卡、`xh_notes_v1` 知识点（含卡片所属章节）、`xh_last_v1` 上次计划、`xh_history_v1` 档案、`xh_pick_v1` 上次选择、`xh_lib_v1` 导入的目录、`xh_pomo_v1` 番茄（含自定义专注时长 / 白噪音选择 / 音量 / 通知开关）、`xh_fetch_v1` 抓取服务地址），不联网、不上传。换浏览器、换电脑、清理浏览器数据都会丢——重要的卡片记得用"导出 txt"存一份，导入的目录要重新粘一次。

## 技术说明

- 单个 `index.html`，约 3300 行，内联 CSS + 内联数据 + 原生 JavaScript（ES6，无框架）
- 零依赖、默认无网络请求，断网可用；**只有你配了抓取服务时**才会去请求它（`fetchOutline()` 带超时，本机助手没开时 2.5 秒探活失败就跳过，不拖慢查章节）
- 章节数据是 `const CHAPTERS` 对象，格式 `{ 书名: { info, suggest, note, list: [{n, title, desc}] } }`；导入的书同名情况下内置永远优先
- 目录解析走 `parseOutline()`（切行 → 剥点线页尾 → 去出版信息噪声 → 认章节标题 / 编号式目录 → 去编号前缀 → 去重），只产出 `{n,title,desc}` 对象，导入的垃圾数据在 `loadCustomLib()` 里再校验一次；`📋 读剪贴板` 走 `navigator.clipboard.readText()`，浏览器不给权限时自动降级成"点框 Ctrl+V"
- 检索走 `searchSections()`（去标点规范化 + 别名匹配），排布走 `buildPlan(subject, totalSections, dailyMin, sections)`，规则在 `RULES` 表里
- 页面启动会自检三件事并把结果打到控制台：HTML 内 id 是否重复、章节数据是不是 `{n,title,desc}` 对象（防回退成旧版三元组）、`buildPlan` 跑一遍后 31 天 / 章节数 / 节点结构是否完整
- 桌面和手机都能用：320 / 360 / 390 / 414 / 480 五个宽度、四个页签 + 章节弹框都实测过，无横向溢出、无文字被裁

## 已知边界

- **不想复制粘贴，就配一个抓取服务**：`outline-fetcher/local.js`（本机跑，页面自动发现）或 `outline-fetcher/worker.js`（部署 Cloudflare Workers，手机也能用）。配好之后输入书名就能自动出目录；没配或抓不到会**自动退回复制粘贴**，不会卡住
- **抓取服务只认微信读书有公开目录的书**：付费/受限/没上架目录的书（例如部分畅销新书）抓不到，会提示原因并退回导入；同名书多时优先选"书名最贴近 + 阅读人数多"的那本，不匹配就换个更精准的书名再试
- 导入的 / 抓来的书只有章名，没有简介，也不带"建议先学哪几章"的人工理由（默认按前 3 章建议）
- 导入的书存在本机，换浏览器或清缓存要重粘一次
- "每天投入"决定三件事：一天最多啃几节、每项任务的分钟数、预算有富余时补不补加练；单节环节有上限，不会把"记关键词"拉成 80 分钟
- 计划是规则推算出来的模板，不知道你的真实进度：跳过的天数要自己打卡补上，不会自动顺延
- 没有账号、没有云同步，一切都在本机浏览器里
