# 学习闭环 · 30 天计划生成器

把一本专业书拆成 Day 0 到 Day 30 的逐日动作表，配合六步学习法、番茄钟、知识点卡片，形成一个"学新 → 检索 → 间隔重复 → 建网"的闭环。

单文件网页，双击就能用：不需要装环境、不需要联网、不依赖任何框架或 CDN。

**在线体验：** https://chengyi-mountain.github.io/study-loop/ —— 手机、电脑都能直接打开，不用下载；离线使用就把 `index.html` 存到本地双击。

---

## 快速开始

1. 双击 `index.html`，用浏览器打开
2. 输入书名（或直接点下方的内置书目）→ 点 **🔍 查章节**
3. 在弹框里勾选要学的章节（默认全不选，只有建议先学的章节有黄色高亮；也可以点"只选建议章节"一键选）
4. 点 **生成我的学习计划** → 自动排出 31 天

选中章节后若什么都不勾直接生成，会按该书内置的建议章节兜底，不会给你一张空表。

## 计划是怎么排出来的

- **31 天**：Day 0 ~ Day 30，每天一张卡，卡片上有当天任务、每项任务的分钟数、以及"产出"要求
- **6 个固定检索节点**：Day 0 / 1 / 3 / 7 / 14 / 30，对应"当天闭卷默框架 → 整章重默 → 三天后合卷 → 一周回顾 → 半月整合 → 月末全书闭卷"。节点日不会被学新内容挤掉，新内容会绕开它
- **日型分三类**：检索节点日（橙色竖标）、学新内容日、机动日（按回炉 / 混合 / 拓展轮着来）。勾选的章节按"总章节数 ÷ 学习日数"均分到学新日，剩下的日子不塞新内容，只做回顾、补漏和拓展
- **每天 3~7 项任务**：预算紧时精简到 3 项核心，预算宽裕时自动补 1~2 条加练（回炉已学章节），第一项是 3 分钟的短任务，用来"把脑子拽回来"
- **每天投入（30 / 45 / 60 / 90 / 120 分钟）是真预算**：扣掉 5 分钟机动后，剩余全部落到当天任务上
  - 30 分钟 → 全天约 25 分钟，砍到「带问题进场 / 只记关键词 / 闭卷默框架」三项，不硬塞五项
  - 45~60 分钟 → 标准六步流程，全天 35~55 分钟
  - 90~120 分钟 → 单节环节放到上限（记关键词最多 35 分钟），剩下的时间补加练，全天 73~115 分钟
  - 预算连三项都装不下时，计划页顶部直接给建议分钟数；章节多到 31 天排不完时会提示少勾几章
  - 计划页右上角也有同一个下拉，改完立刻重排，不用退回起始页

计划页顶部有统计卡（共排几节 / 每天几分钟 / 几个检索节点 / 几个学习日）、打卡进度条、筛选器（全部 31 天 / 只看检索节点日 / 只看未打卡），复选框打卡会即时存盘。

## 四个页签

| 页签 | 作用 |
| --- | --- |
| 学习计划 | 31 天逐日动作表、打卡、筛选、换书重排、清空打卡 |
| 六步学习法 | 完整方法论：五条底层逻辑表、六步闭环详解（每步的动作 / 工具 / 关键）、检索节奏表（第 0~5 次各练什么）、卡壳与拖延的补充模块 |
| 番茄钟 | 25 / 5 / 20 分钟三档，可填"这个番茄做什么"，25 分钟结束自动提示并累计，四个番茄进长休息 |
| 知识点总结 | 三句话（定义 / 区别 / 例子）+ 三方向（深度 / 横向 / 纵向）建卡片，支持搜索、自测（答案模糊，点"看答案"揭开）、导出 txt |

## 内置书目

认知天性、学习之道、如何高效学习、教育学原理、数据结构、四级核心词汇。

每本书都带简介、建议先学的章节和理由、完整章节目录（章名 + 一句话简介）。输入不在这六本里会提示找不到，并列出可用书目。

## 数据存在哪

章节选择、打卡记录、知识点卡片、番茄计数都只存在**你自己浏览器**的 localStorage 里，不联网、不上传。换浏览器、换电脑、清理浏览器数据都会丢——重要的卡片记得用"导出 txt"存一份。

## 技术说明

- 单个 `index.html`，约 2700 行，内联 CSS + 内联数据 + 原生 JavaScript（ES6，无框架）
- 零依赖、零外链、无网络请求，断网可用
- 章节数据是 `const CHAPTERS` 对象，格式 `{ 书名: { info, suggest, note, list: [{n, title, desc}] } }`
- 检索走 `searchSections()`（去标点规范化 + 别名匹配），排布走 `buildPlan(subject, totalSections, dailyMin, sections)`，规则在 `RULES` 表里
- 页面启动会自检三件事并把结果打到控制台：HTML 内 id 是否重复、章节数据是不是 `{n,title,desc}` 对象（防回退成旧版三元组）、`buildPlan` 跑一遍后 31 天 / 章节数 / 节点结构是否完整
- 桌面和手机都能用：320 / 360 / 390 / 414 / 480 五个宽度、四个页签 + 章节弹框都实测过，无横向溢出、无文字被裁

## 已知边界

- 章节库只有内置的 6 本，其他书不支持自动查目录（可以只按"科目"生成通用计划，或自己往 `CHAPTERS` 里加一本）
- "每天投入"决定三件事：一天最多啃几节、每项任务的分钟数、预算有富余时补不补加练；单节环节有上限，不会把"记关键词"拉成 80 分钟
- 计划是规则推算出来的模板，不知道你的真实进度：跳过的天数要自己打卡补上，不会自动顺延
- 没有账号、没有云同步，一切都在本机浏览器里
