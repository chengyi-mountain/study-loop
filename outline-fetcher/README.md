# 目录抓取服务（outline-fetcher）

给 [学习闭环 · 30 天计划生成器](../index.html) 用的「联网抓目录」小服务。
输入书名 → 它去抓这本书的完整目录 → 返回给网页 → 网页直接弹出章节勾选框。
**你不用再复制粘贴。**

两个版本，选一个就行：

| 版本 | 文件 | 适用 | 手机能用吗 |
| --- | --- | --- | --- |
| 本地版 | `local.js` | 只有自己一台电脑用，最省事（不用部署） | ❌ |
| 云端版 | `worker.js` | 想手机也能自动抓（部署一次，免费） | ✅ |

## 它凭什么能抓到（原来纯前端为什么不行）

网页里的 `fetch` 抓豆瓣/微信读书会被浏览器拦掉，因为那两家**响应里没有 CORS 头**。
但这个服务跑在 Node / Cloudflare 上，服务端没有跨域限制，所以能直接取。

真正好用的数据在这里：微信读书每本书的公开阅读页 HTML 里，内嵌了一份完整的
`"chapterInfos":[...]`（章节标题、层级、字数），**不需要登录、不需要会员**。
服务做的事就是：

```
按书名搜索 → 拿 bookId 与 readerLink
          → 取阅读页 HTML
          → 抠出 "chapterInfos":[...]（括号配对解析）
          → 清洗（去版权页/封面/书名当第一章、跨分部重名加前缀）
          → 返回 [{n, title, level}]
```

## 用法一：本地版（推荐先试这个）

需要 Node 18+（本机 `node -v` 能看到版本号就行）。

```powershell
node outline-fetcher\local.js
```

看到这样就成了：

```
学习闭环 · 目录抓取助手  已启动
地址： http://127.0.0.1:8765
```

然后：

1. 别关这个窗口（关掉网页就退回复制粘贴）
2. 打开 `index.html`，输入一本没有内置目录的书，点 **🔍 查章节**
3. 它会自动连 `http://127.0.0.1:8765`，抓到目录就直接弹出章节勾选框

端口被占用就换一个：`$env:PORT=8799; node outline-fetcher\local.js`
然后在网页「导入弹框 → 抓取服务」里填 `http://127.0.0.1:8799`。

直接验接口：

```
http://127.0.0.1:8765/outline?book=认知天性        → JSON，59 章
http://127.0.0.1:8765/outline?book=红楼梦&format=text → 纯文本目录，一行一章
http://127.0.0.1:8765/search?book=道德经           → 只返回候选书名
http://127.0.0.1:8765/health                      → 探活
```

## 用法二：云端版（手机也能用）

1. 打开 https://dash.cloudflare.com → **Workers & Pages** → **Create** → **Worker**
2. 名字随便起，比如 `outline-fetcher`，进编辑器后把 `worker.js` 全文粘进去
3. 点 **Deploy**，拿到地址，形如 `https://outline-fetcher.xxx.workers.dev`
4. 打开网页 → 导入弹框 → 抓取服务 → 粘上这个地址 → **保存地址**

之后手机浏览器打开线上版，输入书名点查章节，同样直接出目录。
（免费额度对个人用完全够；同一书名 30 分钟内走内存缓存，不重复抓。）

## 接口约定（网页这边就是这么调的）

`GET /outline?book=<书名>`

```json
{
  "ok": true,
  "source": "weread",
  "book": { "title": "认知天性：让学习轻而易举的心理学规律", "author": "...", "bookId": "...", "readerLink": "..." },
  "chapters": [ { "n": 1, "title": "引言", "level": 1 }, ... ],
  "candidates": ["认知天性：让学习...", "认知天性（青少版）"]
}
```

失败时 `ok:false` 并给 `reason`，网页会把原因写在提示里，并退回复制粘贴那一套：

| reason | 含义 |
| --- | --- |
| 微信读书里没搜到这本书 | 关键词太生僻/书名不对 |
| 没搜到书名相近的书 | 搜到的都不含关键词，宁可不猜 |
| 搜到的前几本都没有公开目录（付费/受限/还没上架目录） | 目录没公开，只能复制粘贴 |

## 边界（说清楚，免得你踩坑）

- **只认微信读书有公开目录的书**。付费/受限/没上架目录的书抓不到，会自动退回复制粘贴，不会卡住。
- **候选书名可能不是你想要的那本**。同名书很多（比如《人类简史》既有房龙的也有尤瓦尔的），
  服务会优先选「书名最贴近 + 阅读人数多」的；不匹配就换个更精准的书名再试。
- **抓的是目录结构，不是正文**，不存任何书本内容，不落盘、不登录、不碰用户数据。
- **接口随时可能变**。它依赖微信读书公开页面的结构，对方改版就得改解析（改一处 `sliceChapterInfos`）。
  自用、学习没问题；商业或大流量请别这么打人家的接口。
